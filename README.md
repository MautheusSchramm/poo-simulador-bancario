# Simulador Bancário em Java

Projeto simples para praticar Programação Orientada a Objetos.

## Conceitos praticados

- classes e objetos;
- atributos privados e encapsulamento;
- construtores;
- métodos;
- composição entre `Cliente` e `ContaBancaria`;
- validações básicas.

## Como executar

```bash
javac -d out src/*.java
java -cp out Main
```

## Funcionalidades

- consultar saldo;
- depositar;
- sacar;
- transferir entre contas.

Projeto educacional, sem persistência de dados ou dinheiro real.
